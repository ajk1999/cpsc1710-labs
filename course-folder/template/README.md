# My CPSC 1710 folder

Everything for the course in one place. Open this folder with Codex or Claude Code and the agent can see all of it.

| Folder | Put here |
|---|---|
| `course/labs/` | A copy of the labs site. Updated by saying "update my course folder". Do not edit. |
| `course/handouts/` | Homework handouts and other files you download from Canvas |
| `course/slides/` | Lecture slides you download |
| `work/` | Your own homework and lab work, one folder per assignment |
| `notes/` | Your notes. Your agent saves study notes here too. |
| `notes/grill-me/` | Midterm practice: your progress, your mistakes, and a log of each session |
| `projects/` | Final project and experiments |

Keep everything. Do not tidy by deleting.

`AGENTS.md` tells your agent how to behave in this folder, including the course's rules about AI. You can read it and add to it.

Guide: https://cpsc1710.github.io/labs/course-folder/
