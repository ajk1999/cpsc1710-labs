Lab 05 · A small GPT, pseudocode, and API calls again

Read a GPT. Say it in pseudocode.

Walk through a small GPT with a guide, practise the pseudocode the midterm asks for, and finish the API calls from last week.

What are we doing?

Three things, each building on something you have already done.

On Tuesday we saw how attention lets a model look back. Today you see the whole thing built: a guided tour of Andrej Karpathy's notebook, which makes a small GPT from an empty page. Homework 5 starts from that tour.

Then pseudocode. The midterm is on paper, and several questions ask you to write out steps with no computer. We will look at four answers to a question from Homework 4 and decide together what earns full marks.

Last, the API calls from Lab 4. Many course keys did not work last week, so we will run that notebook again, and then write one API call as pseudocode.

Your Homework 4 feedback. A one-page summary of what the class said, and what changes this week: what you told us in Homework 4.

A 70-minute plan

Three parts. The homework begins in the first one.

  1. 0–25 minutes: step through the guided tour together, then open the notebook.
  2. 25–45 minutes: pseudocode. Vote on four answers, then compare.
  3. 45–65 minutes: run the Lab 4 API notebook with your key, then write one API call as pseudocode.
  4. 65–70 minutes: start Homework 5.
