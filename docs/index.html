The 3 closest examples

    3-nearest neighbors: measure straight-line distance using both sliders equally, then take the majority label among the three closest examples. Distance = √((spoon difference)² + (container difference)²). Distances shown are rounded to two decimals; selection uses full precision. Equal distances are resolved using a fixed dataset order. Food presets supply only slider values, not labels, and are never added to the training set. The model always chooses Soup or Salad—even when neither describes the food well.
