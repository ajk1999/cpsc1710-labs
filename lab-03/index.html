Where should I run a notebook?
  • Colab in the browser: nothing to install. The best choice if you just want it to work.
  • VS Code with a Colab server: the notebook stays in VS Code, next to your Git and Codex work, but runs on Google's servers. Install the Jupyter and Colab extensions, click Select Kernel → Colab → Auto Connect, and sign in with Google. See Google's setup guide.
  • VS Code with Python on your computer: works offline, but you install Python and the packages in requirements.txt yourself. Choose this once you're curious how Python environments work.

To run the warm-up outside Colab, download the notebook file.
