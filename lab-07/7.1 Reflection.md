# 7.1 Reflection

The harness did considerably more than the model itself, which I knew would be the case but found pretty interesting the extent to which.  Python did the bulk of the opening, copying, pasting, etc. which allowed it to deterministically follow instructions. It even copied "(leave the argument empty)" straight into its first request, so it really only follows instructions.  Python functions like days_until also lived outside the model.  All told this exercise was informative in showing where the boundary is and what lives on either side of it.
